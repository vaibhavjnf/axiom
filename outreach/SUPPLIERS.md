## How we’ll find them

1. **CM (Shenzhen / Foxconn-tier mid)** — Intro via hardware networks, Elecduino/Maker community referrals, Global Sources / HKTDC directories, and warm intros from other crowdfunding hardware founders. Prefer mid-volume CMs comfortable with 1k–20k first runs, NRE transparency, and English PM.
2. **Enclosure CNC / MIM** — Same CM ecosystem or specialist machine shops in Dongguan/Shenzhen; request DFM on Ø78 × 28 mm puck, anodize coupons, magnet pocket tolerances.
3. **Battery (UN38.3)** — Pack vendors who already ship UN38.3 + MSDS; cell chemistry ~15 Wh class; protection PCB; air-shipping experience for crowdfunding fulfillment.
4. **MagSafe-compatible magnets** — Vendors experienced with phone-accessory magnet arrays; ask for pull-force fixtures and Ø55 mm ring class samples — verify compatibility empirically (not by logo claims).
5. **FCC / CE labs** — Accredited EMC / wireless / safety labs with Bluetooth + Wi-Fi experience; sequence pre-scan → cert; India WPC later as needed.
6. **Audio MEMS / speaker** — Digi-Key / Mouser class for EVT; factory direct for volume ICS-43434-class mics and 20 mm speakers with datasheet SPL.

**Process:** RFQ sheet from `brand/PRODUCT_SPEC.md` → NDA if required → sample PO → dual-source critical parts where possible.
